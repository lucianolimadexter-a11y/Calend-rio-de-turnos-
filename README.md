# 📆 Calendário de Turnos — Refusão

![Capa](capa.png)

App web (HTML/JS puro, PWA) para consultar a escala 6×2 da Refusão, com previsão do tempo, notas e anexos por dia.

## Como usar

Abra o `index.html` direto no navegador do celular, ou hospede como PWA (GitHub Pages, Netlify, etc.) para poder instalar na tela inicial.
